🧪 OmniSearch Custom Shortcuts Test Suite

⚠️ Important: Load the OmniSearch extension in Chrome before running these tests. Make sure you have the latest version with the custom shortcut fixes.

🔧 Basic Custom Shortcut Management

Test Case 1: Add Custom Shortcut

  1. Click the OmniSearch extension icon
  2. Click the + Add Custom button
  3. Fill in the form:
    • Keyword: reddit
    • Website Name: Reddit
    • Search URL: https://www.reddit.com/search/?q=%s
  4. Click Save
Expected Result: Success notification appears, modal closes, Reddit shortcut appears in the list with Edit and Delete buttons visible.

Test Case 2: Edit Custom Shortcut

  1. Find the Reddit shortcut created in Test Case 1
  2. Click the Edit button
  3. Change the Website Name to Reddit Community
  4. Click Update
Expected Result: Edit modal opens with pre-filled values, keyword field is disabled, success notification shows "updated", shortcut name changes to "Reddit Community".

Test Case 3: Delete Custom Shortcut

  1. Find the Reddit shortcut
  2. Click the Delete button
  3. Confirm deletion in the dialog
Expected Result: Confirmation dialog appears, after confirming, success notification shows "deleted", shortcut disappears from list.

⚠️ Edge Cases and Error Handling

Test Case 4: Invalid Keyword

  1. Try to add a shortcut with keyword: test-site (contains hyphen)
  2. Try to add a shortcut with keyword: Test Site (contains space and uppercase)
Expected Result: Error message: "Keyword can only contain lowercase letters and numbers."

Test Case 5: Missing %s in URL

  1. Try to add a shortcut with URL: https://example.com/search?q=test (no %s)
Expected Result: Error message: "URL must contain %s as a placeholder for the search query."

Test Case 6: Duplicate Keyword

  1. Try to add a shortcut with keyword: youtube (already exists as default)
Expected Result: Error message: "A shortcut with this keyword already exists."

Test Case 7: Special Characters in Names

  1. Add a shortcut with name: Stack Overflow Q&A
  2. Add a shortcut with name containing emojis: 🎵 Music Site
Expected Result: Both shortcuts should be created successfully and display correctly in the list.

🔍 Smart Detection Integration

Test Case 8: Smart Detection Edit/Delete

  1. Navigate to a website like reddit.com or stackoverflow.com
  2. Click the OmniSearch extension icon
  3. If smart detection works, click Add as Shortcut
  4. Try to edit the auto-created shortcut
  5. Try to delete the auto-created shortcut
Expected Result: Auto-detected shortcuts should have fully functional Edit and Delete buttons, just like manually created ones.

🚀 Functional Testing

Test Case 9: Test Custom Shortcut in Omnibox

  1. Create a custom shortcut (e.g., keyword: test)
  2. Type os in Chrome's address bar
  3. Press Tab
  4. Type test hello world
  5. Press Enter
Expected Result: Browser should navigate to the custom search URL with "hello world" as the search term.

Test Case 10: Toggle Custom Shortcut

  1. Create a custom shortcut
  2. Toggle it off using the switch
  3. Try to use it in the omnibox
  4. Toggle it back on
  5. Try to use it again
Expected Result: When disabled, shortcut shouldn't appear in omnibox suggestions. When enabled, it should work normally.

💾 Persistence and State Management

Test Case 11: Persistence Across Sessions

  1. Create several custom shortcuts
  2. Close the popup
  3. Close and reopen Chrome
  4. Open the OmniSearch popup again
Expected Result: All custom shortcuts should still be present with Edit and Delete buttons working.

Test Case 12: Multiple Operations

  1. Add 3 custom shortcuts
  2. Edit the second one
  3. Delete the first one
  4. Add another shortcut
  5. Toggle one off and on
Expected Result: All operations should work smoothly with proper success notifications and UI updates.

⚡ Performance and UI Responsiveness

Test Case 13: Rapid Operations

  1. Quickly add 5 custom shortcuts
  2. Rapidly click Edit buttons on different shortcuts
  3. Quickly delete multiple shortcuts
Expected Result: UI should remain responsive, no duplicate modals, proper state management throughout.
