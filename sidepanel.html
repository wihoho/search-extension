OmniSearch

Enjoying OmniSearch? A quick review helps other people find it. It takes 20 seconds.

In the address bar, type os, press Space, then a keyword and your search: os youtube cats

    Tips
    • Type only the keyword, like os youtube, to open the site.
    • Keywords can be shortened: os you cats works if no other keyword starts with “you”.
    • After typing your search, press ↓ to run the same search on another site.
    • Search several sites at once: os youtube+amazon cats.
    • Press Alt+Enter to open results in a new tab.
    • Right-click any site's search box and choose Add a keyword for this search.
    • No matching keyword? OmniSearch runs a normal web search instead.

    Open this panel: Ctrl+Shift+S

    Add shortcut

    Search the site once, then paste the address of the results page. OmniSearch finds where your words go. You can also type the address with %s in place of the words.
    You'll type os ex your search
    Advanced: type into the page instead

    For sites without a search URL, such as some AI chat tools. OmniSearch opens the page, types your words into the box and presses the button. It needs your permission to access that one site.

    Tip: right-click the box on the page, choose Inspect, then right-click the highlighted code and choose Copy › Copy selector.
