How to Use OmniSearch

Basic Usage

Type os in Chrome's address bar, then press Tab or Space to activate OmniSearch.

Search Examples

  • os youtube cats - Search YouTube for "cats"
  • os drive quarterly report - Search Google Drive for "quarterly report"
  • os amazon laptop - Search Amazon for "laptop"

Custom Shortcuts

Add your own search shortcuts by clicking the "+ Add Custom" button. Use %s as a placeholder for the search query in the URL.

Example: https://example.com/search?q=%s
