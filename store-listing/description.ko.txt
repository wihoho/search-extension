Chrome 주소창에서 어떤 사이트든 바로 검색하세요. os를 입력하고 스페이스나 Tab을 누른 뒤 키워드와 검색어를 입력하면 됩니다(예: "youtube 고양이"). OmniSearch가 바로 검색 결과를 엽니다.

주요 기능
• 바로 쓸 수 있는 단축어 10개: 동영상, 이메일, 쇼핑, 백과사전 등 인기 사이트용입니다. 사이드바에서 모두 확인하고 수정할 수 있습니다.
• 검색 페이지가 있는 사이트라면 직접 단축어 추가: 키워드와, 검색어 자리에 %s를 넣은 검색 URL만 지정하면 됩니다.
• AI 채팅처럼 검색 URL이 없는 사이트를 위한 고급 단축어: 페이지를 열고, 지정한 입력란에 텍스트를 입력하고, 버튼까지 대신 눌러 줍니다.
• 모든 것을 관리하는 사이드바: 툴바 아이콘을 클릭하거나 Ctrl+Shift+S(Mac은 Cmd+Shift+S)를 누르세요. 페이지를 가리지 않고 오른쪽에서 밀려 나옵니다.
• 단축어 켜기/끄기, 수정, 삭제를 언제든지 할 수 있습니다.

사용 방법
1. 주소창에 os를 입력하고 스페이스나 Tab을 누릅니다.
2. 키워드와 검색어를 입력합니다. 예: youtube 파스타 만드는 법
3. Enter를 누릅니다.

개인정보 보호
단축어는 Chrome 자체 저장소에 저장되고 Chrome 프로필과 동기화됩니다. OmniSearch에는 계정, 광고, 추적이 없으며, 방문한 페이지의 내용을 수집하거나 전송하지 않습니다. 요청한 검색 페이지만 열고, 고급 단축어는 설정한 사이트에서만 입력합니다.

확장 프로그램 화면은 영어로 표시됩니다.
